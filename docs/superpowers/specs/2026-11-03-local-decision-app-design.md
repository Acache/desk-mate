# 本地决策优化与独立 macOS App

用户已认可：模型预热驻留、R2 提示词、上下文及输出精简、真实表达评测；App 自带 Python、AX helper、STT 与 Ollama 运行时和模型，摆脱目标机开发环境。

## 决策

保留规则 → 个性化分类器 → Ollama 的分层。仅完整匹配的简单指令走规则；组合、否定、问句和修正不得被单个动作词截断。所有来源共用 policy guard、planner 和回读。分类器只处理已验证的简单意图。

Ollama 默认 qwen2.5:1.5b，启动后台预热，显式驻留；健康检查分别报告服务、模型安装及加载。请求使用完整动作参数规范、精简的新鲜上下文和严格 JSON；不得缓存依赖当前播放器的最终计划。记录路由、决策耗时及模型推理耗时。

评测只生成提案及校验计划，绝不调用播放器动作。数据覆盖明确指令、口语、组合、否定、缺失上下文和不支持动作；报告完整动作参数匹配、漏动作、澄清及耗时，保留逐条证据。

## App

原生菜单栏壳管理独立 Python 和 Ollama 子进程，运行于登录用户会话；提供状态、BLE 选择、权限引导、日志及明确确认后的 B 站 CDP 重启。独立 App 数据目录在 Application Support，模型资源只读放于 bundle，用户身份及私钥在首次启动时生成。

构建机需要 Python/Swift 等工具，目标机不需要。构建接收独立 Python 分发、运行依赖、Ollama 分发及指定模型，拒绝缺失资源。不得将用户数据库、凭证、录音或整个模型仓库放入包。打包后检查二进制外部链接、资源完整性与移动后的启动。

## 验收边界

自动化测试、真实 Ollama 推理、App 编译及资源检查、桌面授权及 BLE 真机验收分别记录。未提供 Developer ID 时可生成本机 ad-hoc 签名包，但不得声称已公证或适合对外正式发布。不自动中断已有 B 站/语音服务。
