# 当前链路更新

语音默认使用 BLE，与第 2 屏选定的同一台 Mac 共用连接；原 Wi-Fi 链路可从 Network 手动选择。详见 [BLE 语音桥接](BLE_VOICE.md)。以下电脑授权、改名与管理规则继续适用。

# 第 3 屏：语音电脑管理

更新：2026-11-02。本轮按已确认的英文“语音优先”设计实现。真实连接、语音执行和多台 Mac 的联测由用户验收；没有执行端到端测试。

## 日常使用

- 第 3 屏顶部电脑条显示当前目标和连接状态，点击进入 `VOICE COMPUTERS`。
- 按住物理 **KEY** 录音，中央保留 21 条实时麦克风音量柱和大字号 `mm:ss` 计时。安静时回落到短线。
- 松开后保留原来的取消窗口，显示读秒和缩短的进度条；再按 KEY 取消。
- 录音/发送/等待结果时目标锁定；PWR 短按请求取消并返回 Focus，长按约 4 秒仍全局关机。
- `LAST` 显示最近结果，点击查看原目标电脑和结果。BOOT 的两次确认重放仅属于原电脑的会话，切换目标后会清除重放准备状态。
- 原有顶部三点分页位置和显示时长保持，不增加底部三点。

## 保存与切换电脑

最多保存 5 台语音电脑，一次控制 1 台。授权记录按 server_id 保存；BLE 模式通过身份绑定关联第 2 屏的同一蓝牙目标。蓝牙连接不等于语音服务就绪。

点击电脑 → `CONNECT / SWITCH` → 确认连接。BLE 模式连接该授权身份已绑定的蓝牙目标，并等待其助手认证、返回语音就绪；首次未绑定时先在第 2 屏连接 Mac 并启动助手。Wi-Fi 模式完成可信 WSS 握手后才提交为当前目标，失败尝试恢复旧 Wi-Fi 目标；列表不会自动挑选另一台机器。连接中/恢复中可在 `CONNECTION CHECK` 查看状态。

`MANAGE COMPUTER` 提供：

- `RENAME`：英文显示名，可触摸键盘，也可 BOOT/KEY 选键、PWR 输入；勾选键或 `SAVE NAME` 保存。
- `USE AT STARTUP`：设为 Wi-Fi 语音启动默认；列表 `*` 为该默认标记。BLE 连接目标遵循第 2 屏，自动回连开关保持独立。
- `DISCONNECT`：保留授权，暂停语音自动重连；点击连接后恢复。
- `REMOVE COMPUTER`：二次确认，默认保留。移除当前电脑后不会自动切到其他电脑。本机移除不等于 Mac 服务端撤销令牌。

管理页 BOOT 上一项、KEY 下一项、PWR 确认；长按 BOOT 返回。退出后等待按键松开，避免同一次按压穿透为录音。
列表较长时用 `MORE COMPUTERS >` 翻页。

## 添加另一台 Mac

1. 新 Mac 按 README 安装并运行本项目语音服务。
2. 在设备管理页进入 `+ ADD COMPUTER`，把设备通过 USB 接到新 Mac。
3. 在新 Mac 的本项目目录执行（路径按本机环境替换）：

```bash
PYTHONPATH=mac/src .venv/bin/python -m voice_assistant.cli pair --port /dev/cu.usbmodem101
```

USB 端口通过 `python -m voice_assistant.cli ports` 查看。电脑名称默认取 Mac 主机名，可在设备上改名。

新授权会追加，已有电脑和已保存 Wi-Fi 保留；相同 server_id 重新授权更新原记录并保留用户别名，不重复占名额。
添加后可以仅保存，也可以进入详情连接新电脑。每台主机的证书和令牌分别保存，运行时仅加载当前连接所需的凭据。
容量满或命令/切换未结束时，新授权会被拒绝；先结束当前操作或移除不用的电脑，再重试。

## 更换 Wi-Fi

进入 `WI-FI / NETWORK` → `CHANGE WI-FI`，在手机上连接：

- 热点：`Desk-Mate-Voice`
- 密码：`deskmate`
- 页面：浏览器打开 `http://192.168.4.1`

输入 2.4GHz Wi-Fi 名称和密码后保存。设备关闭热点并重新连接；电脑授权保留。
页面由固件本地提供，仅在主动进入配网时开放，2 分钟后退出。`CANCEL SETUP` 返回原配置。
Wi-Fi 名称/密码整体保存，失败时保留旧配置。非英文 SSID 可以连接，设备英文字体下显示通用 Wi-Fi 状态。

## 迁移与结果归属

旧单主机配置会迁为第一台 `My Mac`，原令牌和证书保留，成功迁移后移除旧位置的重复凭据。
待结算命令恢复到原电脑查询；原电脑无法恢复时，检查原电脑的实际结果，再用 KEY/BOOT 确认 UNKNOWN。
反馈保存原服务器身份，不会随切换发往新电脑。
